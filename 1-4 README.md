# Task 1 — summarizeNumbers

## Опис
Функція `summarizeNumbers(numbers)` аналізує масив чисел та повертає об'єкт зі статистикою.

## Функція повертає:
- `count` — кількість чисел у масиві
- `sum` — суму всіх чисел
- `evenCount` — кількість парних чисел
- `max` — найбільше число
- `category`:
  - `"empty"` — якщо масив порожній
  - `"positive"` — якщо сума більша за 0
  - `"non-positive"` — якщо сума менша або дорівнює 0

## Особливості реалізації
- Для обчислень використовується цикл `for`
- Методи вищого порядку не використовуються
- Передбачена обробка порожнього масиву

## Приклад використання

```javascript
console.log(summarizeNumbers([4, 7, 2, 9]));



# Task 2 — processProducts

## Опис
Функція `processProducts(products)` обробляє масив товарів та повертає об'єкт з інформацією про товари.

Кожен товар містить:
- `name` — назва товару
- `price` — ціна
- `inStock` — наявність товару

## Функція повертає:
- `available` — масив назв товарів, які є в наявності
- `totalPrice` — загальну суму цін товарів у наявності
- `cheapest` — назву найдешевшого товару серед наявних
- `priceList` — список рядків з назвами та цінами товарів

## Особливості реалізації
- Для формування списку назв використовується `filter()` та `map()`
- Для підрахунку загальної вартості використовується `reduce()`
- Для пошуку найдешевшого товару використовується цикл `for`
- Для створення списку цін використовується `map()`

## Приклад використання

```javascript
const products = [
    { name: "Чай", price: 50, inStock: true },
    { name: "Кава", price: 120, inStock: false },
    { name: "Цукор", price: 30, inStock: true }
];

console.log(processProducts(products));
